# Wolfy character execution

Preserve the existing Home/More implementation and all unrelated edits.

1. Generate original stylized geometry in Blender 5, one master skeleton, named
   sockets and 28 clips. Export USDZ for iOS and GLB for future web use. Validate
   exports, render orthographic views/turntable/accessory previews, and inspect them.
2. Add workspace-owned progression, append-only XP/Coin ledgers, catalog,
   purchases/inventory/equipment, interaction cooldowns and verified event rewards.
   Serialize wallet mutations and never accept prices or award amounts from clients.
3. Add RealityKit loading/caching, deterministic animation/mood resolution,
   feature flags, Home viewport, Den, Locker, training and debug-only laboratory.
   Keep data/action controls native and preserve Home when assets/backend fail.
4. Test economy and state invariants, build the field app, inspect simulator output,
   and record limits honestly. Hosted migrations and authenticated verification
   require the correct field backend and signed-in session; do not deploy unrelated
   pending migrations.

Deployment target: iOS 17. RealityView on iOS 18+, non-AR ARView on iOS 17.
Editable art source is generated from original geometry, with no third-party models.
